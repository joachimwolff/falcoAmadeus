# Support and citation

## Getting help

Questions, bug reports and feature requests are welcome on the GitHub issue tracker:

[https://github.com/joachimwolff/falcoAmadeus/issues](https://github.com/joachimwolff/falcoAmadeus/issues)

When reporting a problem, please include the falcoAmadeus version (`falcoAmadeus --version`), the
exact command line, the input format and the platform (operating system and CPU architecture).

## Project links

- Developer group: [MHH Bioinformatics and Hematology](https://mhh-bioinformatics-hematology.github.io/)

- Upstream falco: [github.com/smithlabcode/falco](https://github.com/smithlabcode/falco)

## Contributing

Contributions are welcome. Please open an issue to discuss a change before submitting a pull
request, and make sure `make check` and the tests under `test/` still pass.

## Citing falcoAmadeus

If you use falcoAmadeus in your research, please cite the software and the work it builds on:

- Wolff J. falcoAmadeus: quality control of sequencing libraries before alignment.
  [https://github.com/joachimwolff/falcoAmadeus](https://github.com/joachimwolff/falcoAmadeus)
- de Sena Brandine G, Smith AD. Falco: high-speed FastQC emulation for quality control of
  sequencing data. *F1000Research*. 2019;8:1874. doi:10.12688/f1000research.21142.2
- Andrews S. FastQC: a quality control tool for high throughput sequence data.
  [https://www.bioinformatics.babraham.ac.uk/projects/fastqc](https://www.bioinformatics.babraham.ac.uk/projects/fastqc)
